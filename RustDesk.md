# Làm rustdesk nhanh

## Download tailscale

## Login rustdesk = cùng 1 tài khoản 

## Trong Security (Settings Rustdesk) bật enable direct IP access và điền Port -> Apply

## Tại ID thay vì sử dụng ID để connect thì dùng IP tailscale

Ví dụ: 100.XX.XX.XX:<port>

### Kiểm tra IP tailscale: 
```bash
tailscale ip -4
```
